Hauptprojekt · in Betrieb 01

Huddl · Familien-App

Private Web-App (installierbar als PWA) für Familien mit Kalender, Chat, Einkaufslisten, Aufgaben, Stammbaum und Dokumenten-Scanner. Mehrere Familien nutzen sie, die Daten jeder Familie sind strikt voneinander getrennt.

  • Rechtemodell für Eltern, Kinder und Gäste, geprüft auf dem Server
  • Anmeldung ohne Passwort mit Passkeys (WebAuthn)
  • Datenschutz: Kinderdaten besonders geschützt, Datenexport und Konto löschen
  • Tests, Migrationen und Deployment mit Docker Compose
TypeScript React Node.js PostgreSQL Docker
